# 🚀 Run These Commands in PowerShell

## Copy and paste these commands one by one:

### Step 1: Set remote with token
```powershell
git remote set-url origin https://YOUR_TOKEN_HERE@github.com/AyhanEkici/cursoft.git
```

### Step 2: Push all commits
```powershell
git push -u origin main
```

## ✅ After Push

Check: https://github.com/AyhanEkici/cursoft

You should see all your files!

## 🔧 If It Still Times Out

Try using GitHub Desktop:
1. Download: https://desktop.github.com/
2. Sign in
3. File → Add Local Repository
4. Select: `E:\xampp\htdocs\cursoft`
5. Click "Push origin"
